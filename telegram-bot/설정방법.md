# 텔레그램 봇 설정 (5분, 계정 작업)

대시보드 알림을 폰으로 받고(밀어주기), 명령어로 조회(물어보기)하는 설정입니다.
코드는 이미 다 만들어져 있고, **아래 계정 작업만** 하시면 됩니다.

---

## 1. 봇 만들기 (BotFather)

1. 텔레그램에서 **@BotFather** 검색 → 대화 시작
2. `/newbot` 입력 → 봇 이름·아이디 정하면 **토큰** 발급
   (예: `8123456789:AAExxxxxxxxxxxxxxxxxxxxxx`)
3. **이 토큰은 채팅에 붙여넣지 마세요.** 아래 Secret 자리에만 넣습니다.

## 2. 내 chat_id 확인

1. 방금 만든 봇을 검색해 **아무 메시지나 한 번 보냅니다** (예: "안녕")
2. PC에서 (또는 저한테 부탁하셔서):
   ```bash
   TELEGRAM_BOT_TOKEN=<토큰> python telegram_send.py chatid
   ```
   → `chat_id = 12345678` 이 뜹니다. 이 숫자가 내 chat_id 입니다.

## 밀어주기(알림·다이제스트) — GitHub Secret 두 개

이미 워크플로가 준비돼 있습니다:
- **실적 서프라이즈 즉시알림** — `notify.py` (매시간 refresh 뒤 자동)
- **데일리 다이제스트** — `digest.py` (평일 아침 08:00, 트렌드·임박일정·예매·시세급변)

저장소 **Settings → Secrets and variables → Actions → New repository secret** 에 두 개 등록:

| Name | Secret |
|---|---|
| `TELEGRAM_BOT_TOKEN` | BotFather 토큰 |
| `TELEGRAM_CHAT_ID` | 위에서 확인한 chat_id |

등록 후 **Actions → "알림 연결 테스트 (텔레그램)" → Run workflow** 로 발송이 오는지 확인.
(다이제스트를 지금 바로 보려면 **"텔레그램 데일리 다이제스트" → Run workflow**.)

> 로컬에서 직접 보내려면 `secrets_local.py` 에 `TELEGRAM_BOT_TOKEN`, `TELEGRAM_CHAT_ID` 를 넣으면 됩니다(커밋 안 됨).
> 미리보기: `python digest.py --dry-run` (전송 없이 내용만 출력).

## 물어보기(조회봇) — Cloudflare Worker (선택)

`/시세 에이피알`, `/트렌드 티니핑`, `/수출 티앤엘`, `/일정` 처럼 봇에게 물어보는 기능입니다.
이미 쓰고 계신 **Cloudflare Workers** 에 올립니다.

1. Cloudflare → **Workers & Pages → Create → Worker** → 이름 짓고 Deploy
2. **Edit code** 에서 `telegram-bot/worker.js` 내용을 통째로 붙여넣고 Deploy
3. Worker → **Settings → Variables and Secrets** 에 등록:
   - `BOT_TOKEN` = BotFather 토큰
   - `WEBHOOK_SECRET` = 아무 문자열(예: `carrie-2026`)
4. **웹훅 등록** — 브라우저 주소창에 한 번 열기(값 채워서):
   ```
   https://api.telegram.org/bot<토큰>/setWebhook?url=<워커주소>&secret_token=<WEBHOOK_SECRET>
   ```
   `{"ok":true,"result":true,...}` 나오면 끝. 이제 봇에게 `/help` 를 보내보세요.

> 워커는 배포된 `coverage-dashboard.pages.dev` 데이터를 읽어 답합니다(5분 캐시).
> 데이터가 갱신되면 봇 답도 자동으로 최신이 됩니다.

## 요약

| 기능 | 파일 | 필요한 것 |
|---|---|---|
| 실적 서프라이즈 즉시알림 | `notify.py` (refresh.yml) | GitHub Secret 2개 |
| 데일리 다이제스트 | `digest.py` (digest.yml) | GitHub Secret 2개 |
| 조회봇(`/시세` 등) | `telegram-bot/worker.js` | Cloudflare Worker + 웹훅 |

토큰만 등록되면 나머지는 전부 자동입니다.
