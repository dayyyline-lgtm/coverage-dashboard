섹터별 Top Pick

커버리지 실적 요약

대섹터별 정리 · 종목명 클릭 시 상세(연간·분기 실적, 밸류에이션) 패널. 헤더 클릭 시 섹터 내 정렬. 상승=빨강/하락=파랑.

단위 — 시가총액: 조원 · 매출/영업이익: 십억원 · EPS/주가: 원. OPM = 영업이익 ÷ 매출.

밸류에이션 비교

26E PER(x축) 대 컨센서스 상승여력(y축). 버블 크기 = 시가총액, 색 = 섹터.

밸류에이션 테이블

낙폭 = 현재가 ÷ 52주 최고가 − 1 (하락률). 종목은 소섹터 내 시가총액 순. 컬럼 제목의 ⇄ 를 누르면 고점대비 낙폭 → 52주 위치 → 저점대비 반등으로 전환됩니다(제목 클릭은 정렬).

실적 프리뷰 & 컨센 비교

다가오는 분기 컨센서스 실적(네이버 실수집)과, 연간 26E 영업이익의 당사 추정 vs 컨센 괴리. 괴리 ±5% 초과 시 당사 상회 / In-line / 당사 하회.

단위 십억 원. 분기 컨센·연간 컨센은 네이버 금융 재무 API에서 자동 수집(추정치 변경 시 자동 반영), 당사 26E 영업이익은 유니버스 엑셀 기준. 괴리 = 당사 ÷ 컨센 − 1 (양수면 당사가 더 공격적).

이벤트 캘린더

DART 전자공시 + 네이버 IR 일정 실수집 — 기업설명회(IR)는 공시 원문에서 실제 개최일을 파싱했습니다. 종목 칩 클릭 시 상세 패널, 마우스를 올리면 일정 내용이 보입니다.
