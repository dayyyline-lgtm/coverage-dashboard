커버리지 요약

밸류(PER 12MF·26E·27E)·성장(영업익)·수급(외국인)을 한 줄로. 종목명 클릭 시 상세 · 리포트·뉴스는 오늘 → 3일 → 1주일 → 1개월 순으로 창을 넓혀가며 찾는다(리포트는 조회수 1위, 뉴스는 최신). 없으면 빈칸 — 누르면 원문으로 이동.

시총·견적: 억 원 · 상승여력 = 견적÷시총−1 · 낙폭 = 52주 고점 대비. 엑셀엔 배수·추정치까지 전부 포함.

밸류에이션 비교

12MF PER(x축) 대 당사 상승여력(y축, 견적시총÷현재시총). 버블 크기 = 시가총액, 색 = 세부 카테고리.

밸류에이션 상세 (배수 · 실적추정) — 카테고리별

26E = 컨센(API), 27E = 컨센(엑셀) · 단위 매출·영업익·순익 억 원. 맨 오른쪽 ⇄ 로 낙폭↔52주위치↔반등 전환.

실적 프리뷰 & 컨센 비교

당사 추정 vs 컨센서스. 발표 전에는 괴리를, 발표 후에는 실제와 맞춰 누가 더 근접했는지 봅니다. 당사 추정은 MY_EST 한 곳만 편집하면 되고 컨센·실제는 자동 수집됩니다.

보기

단위 억 원. 분기 컨센·연간 컨센은 네이버 금융 재무 API에서 자동 수집(추정치 변경 시 자동 반영), 당사 26E 영업이익은 유니버스 엑셀 기준. 괴리 = 당사 ÷ 컨센 − 1 (양수면 당사가 더 공격적).

이벤트 캘린더

DART 전자공시 + 네이버 IR 일정 실수집 — 기업설명회(IR)는 공시 원문에서 실제 개최일을 파싱했습니다. 종목 칩 클릭 시 상세 패널, 마우스를 올리면 일정 내용이 보입니다.

리서치 리포트

커버리지 종목에 대한 증권사 발간 리포트 — 네이버 금융에서 실시간 수집. 종목별로 묶어 최신 3건씩(상단 섹터 버튼으로 좁히기). 종목명 클릭 시 상세 패널, "보기"로 원문 이동.

뉴스

커버리지 종목 관련 최신 뉴스 — 네이버 금융에서 수집, 종목당 최신 3건. 종목별로 묶어 보여줍니다(상단 섹터 버튼으로 좁히기 가능). 제목 클릭 시 원문 이동, 종목명 클릭 시 상세 패널.

같은 기사가 여러 종목에 걸리면 각 종목 블록에 함께 표시됩니다. 종목 블록 안에서 최신순 정렬.

트렌드 비교

종목을 누르면 그 종목과 엮인 검색 트렌드가 나옵니다. 상대값 0–100. 출처는 주제마다 다릅니다 — 국내 키워드는 네이버·구글 둘 다, 해외 국가별은 구글(러시아는 얀덱스)뿐이라 선택할 게 있을 때만 출처 버튼이 뜹니다.
